# Maze Treasure

2D-игра-лабиринт на Python, Pygame. Управляйте персонажем стрелками, собирайте сокровища, избегайте стражей и найдите выход.

## Управление персонажем

 Клавиша  Действие 
 ↑ ↓ ← →  Движение персонажа 
 Esc      Выход из игры 

## Механика
- **Сокровища** — собирайте их, чтобы зарабатывать очки.
- **Обычные стражи** — патрулируют по своему маршруту, игра завершится если вы попадетесь им!
- **Умные стражи** — если вы попадаете в их поле зрения, замечают персонажа и начинают его преследование.
- **Выход** — найдите его, чтобы завершить игру победой.
- 
У игры есть несколько визуальных образов персонажа и стражей.
